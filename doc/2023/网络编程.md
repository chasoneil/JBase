### 2. NIO

> BIO  NIO AIO

* BIO 同步阻塞模型 IO 我们常见的 Socket 就是这个模型实现，他的关键词是**阻塞**
* NIO 同步非阻塞模型 IO  效率明显高于 BIO
* AIO 异步非阻塞IO  Linux下用的非常少， Windows中有应用

同步和异步：

* 谁发起的请求，在数据好了之后，谁来处理 这就是同步
* 谁发起的请求，在数据好了之后，通过回调程序去做，甚至换个线程进行处理 这就是异步

为什么Java中不使用AIO

* Java 程序大多部署在Linux上， 而在Linux系统上， NIO已经提供了足够的性能
* AIO在Java上的使用不成熟，目前还有很多问题，在Windows上有一些使用，但是大多闭源

> Reactor

Reactor 是一种模式，主要的流程是：

* 注册感兴趣的事件
* 扫描是否有注册事件发生
* 事件发生之后作出相应的处理

Reactor 有三种版本，其实也就是在多线程下的演变：

* 单线程
* 多线程
* 主从多线程
