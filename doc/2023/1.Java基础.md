## Java



### 1. 面向对象和面向过程

* 面向过程更多的是过程性的调用方法，性能相对于面向对象更高，但是逻辑上更难理解，编码难度更高
* 面向对象 具有 继承、多态、封装的特性，编码难度更低，更易于理解，但是运行效率没有面向过程那么高

### 3. instanceof

Java 中的一个双目运算符， 用来判断某个对象是不是一个类的实例。

返回值是一个Boolean

这个用于判断的对象必须是引用类型不能是基本类型的数据，如果是基本类型的数据，编译直接不通过。



----

### 4. 内部类

目的： 提高安全性，定义在内部的类可以不被外界访问发挥作用

* 成员内部类
  * 在外部类的内部定义一个内部类
* 局部内部类
  * 在方法中定义的内部类
  * 只能在方法中访问，对外界完全隐藏
  * 只能访问被生命为final的局部变量 
  * 不能用 public 和 private 修饰
* 静态内部类
  * static 修饰的内部类
  * 属于外部类本身，不属于任何一个对象
  * 只能访问外部类的静态成员
* 匿名内部类

### 5. 浅拷贝和深拷贝

* 浅拷贝：

  是创建了一个新的对象的引用，但是指向的地址还是原来的对象，如果修改原对象的值，克隆的对象也会跟着一起改

  浅拷贝是没法拷贝对象中的引用的

* 深拷贝

  通过序列化和反序列化，完全创建了另外一个对象，是个深度复制，原来对象所引用的对象，也被复制了

### 7. fail-fast

是一种 集合中的错误机制，当多线程同时对一个集合进行内容操作的时候，就可能会产生 fail-fast 事件。

例如： 线程A通过 iterator去遍历集合， 线程B去修改集合的内容，如果两个线程的操作冲突就会出现ConcurrentModificationException

这就是 fail-fast事件。

Java 集合中是通过 modCount 这个变量来记录变化的， 当集合中元素发生变化， modCount++， 当我们遍历的时候，会记录一次

modCount,  当遍历结果发现modCount 发生变化了，意味着我遍历期间集合被改了，那么就抛出异常。

### 9. try-with-resource

对于实现了 Closeable 接口的资源 Resource, 我们在 try 中创建 将不用再去手动关闭

实现的原理在编译之后发现，其实就是编译器帮我们改写了， 在try 中手动创建 ， 在finally 中手动关闭
