

## L2 笔记

### 13  第九课下 两篇游记

2025/12/8  月曜日

> 1、语法

1. 少ない　多い 不能直接修饰名词做定语
   * 少ない人（❌️） 
   * 人が多いですね（✅️）
* たくさん可以在名词前修饰名词表示多
  * たくさんの人がいます

2. い形容词的过去式 将 い 变成 かった
   * 楽しい　　楽しかった
   * おいしい　おいしかった

3. 使用 は 表示对比、强调
   * かわいい服 を 買いました
   * かわいい服 は かいました　强调衣服好看
   * 靴 を 買いませんでした
   * 靴 は 買いませんでした　　对比买了衣服没买鞋

   * （私は） 李さんに　このケーキをもらいました
   * このケーキ　は　李さんに　もらいました　　强调的是蛋糕
   　　
4. い形容词的过去否定 将 い 变成 くなかった
   * 忙しい　忙しくなかった
   * 楽しい　楽しくなかった
* くなかったです　＝　くありませんでした

5. 表示程度的副词：
* とても  たいへん　 很 非常
* 少し　　ちょっと　 稍微 有些
* あまり　＋　否定   不太  不怎么
* 全然　＋　否定     全部否定 完全不

6. から　表示离某地的距离
   * 会社は家から遠いですか
