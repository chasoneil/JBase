> 2、语法
1. n  は n です　　x 是 xx
* 名词 + です　です翻译成是  は　是助词 提示前面的名词  一般是提示主语
  * 私は　李です。
  * 李さんは　中国人です。
  * 小野さんは留学生です。
  * あの人は中国人です。
  
* 简略形式是 n です
  * 李です
  * 学生です

2. 称呼
* ~さん　　　最常见的称呼
* ~ちゃん    用来称呼女生和孩子
* ~君        用来称呼男生和孩子

3. の　常见助词 一般翻译成 的
* 使用方法一般是 n は n の n です
    * 私　　は　東京大学　の　学生です　　　
    * あの人は　JC企画　　の　社員です。

> 3、句子
