> 2、语法

1. に　表示动作方向的对象 向谁 给谁
   * 誰に　電話をかけましたか          （你）给谁打电话

2. A(人) 　は　B(人)　に　 C(物) を　あげます
   * 给需要由内向外 从第一人称到第三人称
     * 私は　愛ちゃんに　チョコレートを　あげます

> 3、句子

* A:誰に　電話をかけましたか
* B:愛ちゃんに　電話をかけました
* A:えっ、愛ちゃんは誰ですか。
* B:お　客　さんです。先週、喫茶店で愛ちゃんに会いました。一緒にご飯を食べました。
* A:そうですか。　女　の子ですね。
* B:はい、ははは。お兄　さん、私はチョコレートを作りました。
* A:チョコレート？食べます！
* B:すみません、お兄さん。愛ちゃんにチョコレートをあげます。
* A:ふん！
