

## L2 笔记

### 07 第五课下 森林大学的大事件

2025/11/21  金曜日

> 1、语法

1. 动词时态1
* ました  表示肯定状态的过去式
   * 昨日　休みました。       昨天休息了。
* ませんでした  表示否定状态的过去式
  * 昨日　休みませんでした。        昨天没休息。

2. と　提示共同做某事的对象  人 + と　+ 动词
   * 私は　先々週　李さんと　一緒に　勉強しました。     我上上周和小李一起学习

3. から　まで　从...(时间)...到...(时间) 
   * 熊（クマ）は　いつも　10月から　　3月まで　寝ます。          熊总是在10月到3月冬眠。
* いつ　后面也可以接 から　まで
  * いつから　いつまで　从什么时候到什么时候

4. 时态总结：
* 现在及将来肯定： ます
* 现在及将来否定： ません
* 过去肯定：　ました
* 过去否定：　ませんでした
              　　
> 2、句子

* 明日　休みます。             明天休息
* 昨日　休みました。           昨天休息了
* 昨日　休みませんでした。     昨天没休息

* 明日　授業が　ありません。　勉強しません。       明天没有课，不学习。
* 昨日　休みました、勉強　しませんでした。         昨天休息， 不学习。

* 私は　先月　熊野(クマノ)　さんと　一緒に　働きました。
* 私は　先々月　熊野さんと　一緒に　旅行しました。

> 3、练习

* A：はい、桜図書館です
* B：すみません、そちらは何時から何時までですか。    不好意思，你那边是从几点到几点（开门）
* A：9時から7時までです。       【时间区间可以直接加です】　9点到7点开门
* B：そうですか。休みは　いつですか。  【休息是名词 后面 + は】　【いつ 可以直接加 ですか】 这样啊，休息日是什么时候呢？
* A：月曜日です。
* B：ありがとうございます。

* 私は　昨日　9時から　研修しました。          我昨天从9点开始研修
* 私は　昨日　5時まで　研修しました。          我昨天研修到5点
* 私は　昨日　9時から　5時まで　研修しました。 我昨天从9点到5点在研修

* 私は　先々週　金曜日まで　田中さんと　一緒に　旅行しました。
