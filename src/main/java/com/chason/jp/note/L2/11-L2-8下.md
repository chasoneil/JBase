

## L2 笔记

### 11  第八课下 秀恩爱的朋友圈 

2025/12/1  月曜日

> 1、语法

1. で　表示原材料
   * 張さんは　いちごで　チョコレート　を　つくります。       张先生用草莓做了巧克力

2. もらいます　表示得到，同样也满足内外关系
   * A  は  B 　に  C　を　もらいます　 A 从 B 那儿得到了C
     * 私は　張さんに　チョコレート　を　もらいました。        我从小张那边得到了巧克力。
   * 从公司，团体，组织得到时，只能用 から　 大多数时候から和に可以互换
     * 父は　社長から　お酒をもらいました
     
3. で　表示方式 方法 手段 工具
   * 張さんは　英語で　「I LOVE YOU」を　書きました。           小张用英语写了I LOVE U
