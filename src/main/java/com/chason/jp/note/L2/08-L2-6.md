> 2、语法

1. へ　提示移动的方向
   * A:　来週は夏休みですね。どこへ行きますか。
   * B:　東京へ行きます。

2. で　表示方式手段
   * A：何で行きましたか。         你是怎么去的呢？（使用什么手段，方式）
   * B：バスで行きました。         坐公交车去的。

3.  [名词(地点)] から +  [名词(地点)] まで   表示从哪里到哪里
   * 中国から日本まで　从中国去日本
             　　
> 3、句子
