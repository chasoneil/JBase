> 2、语法
1. 动去ます　ながら
* 表示两项动作同时进行 翻译成 一边~ 一边~
* 后一个动作是主要动作
  * 山田さんは　テレビを見ながら　本を読んでいます。
  * 話しながら　ご飯を　食べる　の　は　よくない。
  * あなたは　出発の時間まで　何をしながら、待ちますか。

2. て　います　表示反复习惯发生的动作
  * 大阪行きの飛行機は２時間に1便飛んでいます。
  * 仕事で　よく　鈴木さんと　会っています。
  * 発表で　スピーチ　の　練習をしています。
  * わたしは　毎日　日本語を　勉強しています。

3. をして　います 常用来描述自己的职业
  * あなたは　どの都市で、何をしていますか。
  * キムさんは　フランス語の教師をしています。
  * 姉は　エンジニアをしています。
