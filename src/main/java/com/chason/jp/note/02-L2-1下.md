

## L2 笔记

### 02 第一课下　我不是留学生

2025/11/7  金曜日

> 1、语法

1. n は n　ですか /　ではありません
* ですか　表示疑问
* ではありません　表示否定 翻译成不是XX
  * 李さんは　韓国人　ですか。
  * いいえ、韓国人ではありません。
* ではありません 的口语 じゃありません
  * 私は日本人じゃありません。

2. 表示肯定和否定的通用回答：
* はい、そうです
* いいえ、違（ちが）います
* 分（わ）かりません        不知道

3. ですね 表示确认 原来是这样
* A：私は李です。
* B：李さんですね。　原来是小李啊

> 2、句子

* 李：先生、はじめまして。私は李です。
* 先生：李さんですね。李さんは韓国人ですか。
* 李：はい、（私は）韓国人です。どうぞ、よろしくお願いします。


* どうも、すみません。　非常抱歉


* こちらこそ　彼此彼此，哪里哪里

> 3、练习

1. 
* Q:　張さんは東京大学の教授ですか。
* A:　はい、そうです。
* A:　はい、東京大学の教授です。

2. 
* Q:　張さんは韓国人ですか。
* A:　いいえ、違います、中国人です。
* A:　いいえ、韓国人ではありません、中国人です。
