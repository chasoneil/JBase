2、语法
    (1)　n と n　と　どちらが　adj　ですか　（疑问）名词1和名词2哪个更adj...
    例：
    コーヒーとお茶とどちらが好きですか

    (2) (n より) n のほうが　adj です　　（回答）我更喜欢...
    例：
    （お茶より）コーヒーのほうが好きです


    (3) n 「の中」で n がいちばん　adj　ですか   （疑问）三者及以上的事物中最...
    例：
    果物の中で何がいちばん好きですか

    (4) n　がいちばん　adj 　です    （回答）三者以上最...
    例：
    バナナがいちばん好きです
