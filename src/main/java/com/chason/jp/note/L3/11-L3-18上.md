

## L3 笔记

### 11 第十八课上　我想成为海贼王

### 海賊王になりたいです

2026/1/23 金曜日

> 1、单词

1. 单词
* なります-成ります-成为;变成-3-v
* しゃかいじん-社会人-工作的人-2-n
* こえ-声-声音;发声-1-n
* おと-音-声音;自然的声音-2-n
* びょうき-病気-病-0-n
* シャツ--衬衫-1-n
* うるさい--很烦;很吵-3-v
* にあいます-似合います-适合;(不能指人际关系)-3-v
* みじかい-短い-短的-3-adj

2. 短语
* 先生　の　声　　　指通过声带振动发出的声音，比如人声，鸟声
* 時計　の　音      指物体振动发出的声响
* 病気　に　なります　生病
* シャツ　を　一枚　買います
* このシャツはお父さん　に　似合います
* お父さんはこのシャツ　が　似合います

> 2、语法
1. なります　翻译成变成，成为 重点是强调结果状态
* い形容词去　い 变成　く
  * だんだん暖かくなります
  * A:風邪はどうですか
  * B:ゆうべ薬を飲みました、まだよくなりません
* な形容词或者名词 + に
  * 母は病気になりました 
  * 掃除しましたから、部屋がきれいになりました

2. します　也是变化，但是着重描述变化的动作行为
* い形容词去　い 变成　く
  * テレビの音を大きくします
  * A:あのう、ちょっとうるさいですよ
  * B:あっ、すみません、静かにします
* な形容词或者名词 + に
  * リンゴをだくさん買いましたから、ジュースにしました。それから、冷蔵庫に入れて、冷たくしました
  * 部屋をきれいにしてください

> 3、句子
* 髪が長（なが）くなりました
* 髪を短くします
