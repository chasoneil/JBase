> 1、语法

* 17课
  * N + が欲しいです
  * V去ます + たいです
  * V去ます + ましょう　＝　ませんか 一起做某事
  * 全面肯定： 疑问词 + でも/も + 肯定
    * 何でも食べたいです
    * どこでも行きたいです
  * 中に　在...之内
    * じゅうに　日，年
    * ちゅうに  周，月

* 18课
  * 变成  なります     自动
    * は/が　なります
    * （い形容词）くなります
    * （な形容词/N）になります
      * きれいになりたいです
  * 使之变 します
    * は/が　を　します　他动
      * この服をきれいにしたいです
  * ほうがいいです

* 19课
  * な
  * 必须：
    * なければなりません＝なければ＝なきゃ
    * ないといけません＝ないと
  * 请不要 ないでください＝ないで
  * なくてもいいです　不怎么样

* 20课
  * 基本型 
  * 动词名词化 V基本型 + こと
  * ことができます
  * V基本型/Nの + 前に 在...之前
