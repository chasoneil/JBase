> 2、语法
1. 动词 て 型
* 三类动词变法: 将 ます 换成　て
  * 勉強します　勉強して
  * 旅行します　旅行して
  * コピーします　コピーして
  * します　して
  * 来ます　来て
* 二类动词变法: 将 ます 换成 て
  * 食べます　食べて
  * 開けます　開けて
  * つけます　つけて
  * 起きます　起きて
* 一类动词变法: 
  * 一类动词以 ます 结尾的 1段假名是[い ち り]结尾的 将1段和ます 变成 って
    * 買います　買って
    * 待（ま）ちます　待って
    * 撮ります　撮って
  * 一类动词以 ます 结尾的 1段假名是[に び み]结尾的 将1段和ます 变成 んで
    * 死（し）にます　死んで
    * 遊びます　遊んで
    * 飲みます　飲んで
    * 読みます　読んで
  * 一类动词以 ます 结尾的 1段假名是 き 结尾的 将1段和ます 变成 いて
    * 歩（ある）きます　歩いて
    * 書きます　書いて
  * 一类动词以 ます 结尾的 1段假名是 ぎ 结尾的 将1段和ます 变成 いで
    * 泳ぎます  泳いで
  * 一类动词以 ます 结尾的 1段假名是 します 结尾的 します 变成 して
    * 貸します　貸して
    * 出（だ）します　出して
    * 消（け）します　消して
* 特殊：
  * 行きます　行って

2. てください　请xxx
* 动词て型 + ください
  * 住所（住所）と名前を書いてください　请写上地址和姓名
  * すみません、書類をコピーしてください
  * 手紙を出してください
  * どうぞ、読んでください
  * 李さん、ちょっと待って（ください）
