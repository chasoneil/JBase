### 05 第十五课上　我可以吃这个吗

### これ、食べていいですか

学会向他人征询许可

2026/1/9 金曜日

> 1、单词

* もうします-申します-叫-3-v
* ねつ-熱-热-1-n
* かぜ-風邪-感冒-2-n
* むり-無理-勉强;做不到-1-n
* じゅうぶん-十分-充分-3-n
* すいみん-睡眠-睡眠-0-n
* とります-取ります-取得-2-v

* 李　  と　申します    我叫李
* 熱　  が　あります    发热
* かぜ　を　引きます    引起感冒
* 無理　を　します　　  勉强
* 気　  を　つけます    注意
* 睡眠　を　取ります

> 2、语法
1.  动て もいいですか
* 注意：当是问句的时候表示“我可以做某事吗？”
* いいです　=　かまいません　=　大丈夫です
  * A:もう遅（おそ）いです、帰ってもいいですか。
  * B:はい、もちろんです。
  * A:クーラーをつけてもいいですか
  * B:ええ、かまいません、どうぞ。
  * A:ここで寝てもかまいませんか。
  * B:いいえ、それはちょっと...
* 当作为陈述句时候，是表示“你可以做”
  * もう遅いですから、帰ってもいいです。
  * 時間がありますよ。ちょっと買い物してもかまいません。

2. 动て　はいけません　不行，不能做
   * A:教室でご飯を食べてもいいですか。
   * B:いいえ、食べてはいけません。
   * A:ここで遊んではいけませんか。
   * B:いいえ、遊んでもいいですよ。
   * A:バスの中でタバコを吸ってはいけません。
   * B:そうですか、わかりました。
   * A:あっ、ここで携帯電話を使（つか）ってはだめですよ。
   * B:すみません、これから気をつけます。
* てはいけません　＝　てはだめです

> 3、句子

* A:写真を撮ってもいいですか
* B:すみませんが、それは...　

> 4、练习
1. 
* すみません、窓を開けてもいいですか
* すみません、ここでお弁当を食べてもいいですか
  * ここでお弁当を食べてかまいませんか
* このパンフレットをもらってもいいですか

2. 
* すみません、ここでビルーを飲んではいけません
* すみません、大きい声（こえ）で話してはいけません
* 携帯を使ってはいけません
* タバコを吸ってはいけません
  * タバコを吸ってはだめです
