2. 短语
* パスポート　を　忘れます
* 品物　に　触ります
* のど　が　渇きます
* 病気　が　治ります
* 会社　で　残業します
* 財布　を　落とします

> 2、语法
1. は　提示旧信息 が　提示新信息
* わたしは学生です　 常规表示
* わたしが学生です   强调学生身份，例如有人问谁是学生可以这么回答
* 旧信息 は 新信息です
* 新信息 が　旧信息です

2. 动词 ない　型
* 三类： 去ます变成ない
  * 買い物します　買い物しない
  * 旅行します　旅行しない
  * 特殊： 来ます　　来（こ）ない
* 二类： 去ます变成ない
  * 食べます　食べない
  * 開けます　開けない
  * 見ます　　見ない
* 一类：ます前面那个音，变成该行第一个音  去ます变成ない
  * 書きます　書かない
  * 泳ぎます　泳がない
  * 飲みます　飲まない
  * 洗います　洗わない

3. ないでください 请不要做某事
