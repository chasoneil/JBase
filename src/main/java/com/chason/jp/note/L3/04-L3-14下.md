

## L3 笔记

### 04 第十四课下　回到家要做什么呢

### 家へ帰って、何をしますか

能够表达动作的先后顺序

2026/1/7 水曜日

> 1、单词

* たいへん-大変-太;够受的-0-adv;n;adj
* ふなびん-船便-船运;海运-0-n
* おうだんほどう-横断歩道-人行道-5-n
* わたります-渡ります-横渡;穿过-3-v
* こうさてん-交差点-十字路口-0-n
* まがります-曲がります-转弯-3-v
* そつぎょうします-卒業します-毕业-4-v
* おります-降ります-下;(车)-3-v
* とびます-飛びます-飞-3-v
* とおります-通ります-穿过-4-v

> 2、语法
1.  使用 を 
* 移动经过的场所
  * 横断歩道　を　渡ります
  * 交差点　を　曲がります
* 离开的场所
  * バス　を　降ります
  * 電車　を　降ります
  * 大学　を　卒業します
  * 家　　を　出ます
  * 海　　を　飛びます
  * 山　　を　通ります

2. 使用 て 按时间的顺序描述多个动作
* 注意：接的动作最多3个，当出现4个动作最好分两个句子
* デパートへ行って、買い物しました
* 
* A:今日の午後は　何をしますか
* B:図書館へ行って、勉強をします。それから家へ帰って、手紙を書きます。
* 
* 朝起きて、友達と　海へ　行って、バーベキューをしました。

3. 动 てから 动 按时间顺序描述两个相继发生的动作
* 注意：一个句子中只能用一次　先后顺序不可逆
* 日本語を勉強してから出かけます
* この薬は食事をしてから、飲んでください
* 手を洗ってから、ご飯を食べます

> 3、句子

* 没变之前

わたしは家へ帰ります；
宿題をします；
ご飯を食べます

* 变成

わたしは家へ帰って、宿題をして、ご飯を食べます
　
> 4、练习
1. 
* 映画を見て、食事をして、買い物をしました
* 起きて、朝ご飯を食べて、図書館へ行きます
* 友達に会って、店（みせ）に行きました
* テレビを見て、シャワーを浴（あ）びます

2. 
* ご飯を食べてから、薬を飲みます
* 窓を開けてから、掃除します
* 電話をかけてから、本を読みます
* 写真を見せてください
* 書類をコピーてください
* 待ってください
