## 并查集

> 定义

并查集是一种数据结构：
如果有一些元素 a, b, c, d, e, f...

创建一种数据结构，是一些集合，每个元素单独创建一个集合，所以有如下集合：
{a}, {b}, {c}, {d}, {e}, {f}...

并查集提供两个方法： 
boolean isSameSet(a, e); // 判断a元素和e元素在不在一个集合中，返回布尔类型
void union(a, e); // 将a元素所在的集合和e元素所在的集合合并（并集）

做到上面两个方法的时间复杂度： O(1)

> 基本设计

1. 设计一个指向自己的指针结构包装，这个指针结构的代表节点就是按照这个指针找到头
2. 代表节点表示一个集合的头
